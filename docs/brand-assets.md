# Brand assets

The Fireship logo is used to identify the source channel. This is an independent project, not an official Fireship product.

Original SVG from the Fireship-owned website repository:
https://github.com/fireship-io/fireship.io/blob/987da97305a5968b99347aa748f928a4667336f8/hugo/layouts/partials/svg/logo.svg

Local asset: `public/fireship-logo.svg`. The favicon uses the same flame, tilted inside an open index dial.

Barlow Condensed is served locally. Its SIL Open Font License is included at `public/barlow-condensed-license.txt`.

Allo by Josh Puckett is served locally for headings, body text, video titles, controls, and dates.
The unmodified `AlloVariableFriendly.woff2` file uses fixed roundness 50 with variable
weight and optical size. The SIL Open Font License and copyright notices are included
at `public/allo-license.txt`. The hero uses the unmodified
`Allo-MediumOblique.woff2` for its italic phrase.

Source: https://github.com/joshpuckett/allo/tree/4bef023e21d938ab2b6982d3dda5fa334e1e5a9b

All page fonts are served locally. Barlow Condensed remains on the gauge score
and section headings. The existing social image is static artwork.
